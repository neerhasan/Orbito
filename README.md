# Orbito handoff pack

How to use:
1. Copy this whole folder into your project (the repo root). `CLAUDE.md` must be at the root; `docs/` beside it.
2. Open Claude Code in that folder. It reads `CLAUDE.md` automatically.
3. Follow `docs/BUILD-PLAN.md` from "Before M0". Paste each milestone's prompt in order.
4. Test, fill in `docs/TEST-NOTES-TEMPLATE.md`, and bring the notes back to the planning chat.

Folders:
- `product/`: concept, requirements, feature list, user flows
- `technical/`: technology choices, architecture
- `status/`: the project status file
- `design/`: screens, styles and design notes
- `reference/prototype/`: a working web prototype for behaviour
